Cricket Career Simulator

A 2D cricket game built with Python and Pygame, designed to let you experience a cricket career as a batter and wicketkeeper.

 Play the Game

Live Demo: https://nandantirumala13-coder.github.io/cricket-career/

 Features

Play as a batter or wicketkeeper

Cricket-inspired gameplay

A project developed using Python and Pygame

 Built With

Python

Pygame

Pygbag for web deployment

 Running Locally

Install Python 3.

Install Pygame:

python3 -m pip install pygame

Run the game:

python3 cricket_career.py
